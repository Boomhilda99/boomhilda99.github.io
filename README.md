## 📦 Running Locally

Clone the repository:

```bash
git clone https://github.com/boomhilda99/boomhilda99.github.io.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser at:

```
http://localhost:4321
```

## 🏗️ Building

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
